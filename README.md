# INVP01

Конверсионный сайт «AI-дайджест для новичков». На главной — десять карточек. Кнопка **Открыть материал** ведёт на полный разбор. Форма сохраняет почту в файл `subscribers.txt`: так устроена подписка в учебном проекте, настоящие письма не отправляются.

Стек: Flask, HTML, CSS, JavaScript.

## Как запустить

Нужен Python 3.10 или новее. В терминале, из папки проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

На Windows вместо `source .venv/bin/activate` выполните `.venv\Scripts\activate`.

Сайт откроется на [http://127.0.0.1:4721](http://127.0.0.1:4721). Если порт занят, поменяйте число `4721` в конце `app.py`.

Остановить сервер: `Ctrl+C`.

## Как устроены файлы

| Файл | Зачем |
| --- | --- |
| `app.py` | Страницы, форма подписки, запуск сайта |
| `data.py` | Тексты карточек и цвета тем |
| `templates/` | HTML-страницы |
| `static/css/style.css` | Внешний вид |
| `static/js/main.js` | Фильтр тем, полоска чтения, кнопка на телефоне |
| `subscribers.txt` | Появляется после первой подписки, в git не попадает |

## Как добавить карточку

1. Откройте `data.py`.
2. Скопируйте любой блок внутри `MATERIALS`.
3. Поменяйте `slug`, номер, заголовок, тему, текст и минуты.
4. `slug` — это адрес страницы. Пишите его латиницей через дефис: `moya-tema`.
5. Сохраните файл и обновите сайт. Если поле пустое или тема неизвестна, `app.py` остановится и напишет, что именно поправить.

Новая тема добавляется в словарь `TAGS`. Значение — цвет из CSS: `lime`, `amber`, `coral` или `aqua`.
